# v0.1.0

- **Date**: 2026-11-21
- **Previous version**: None.

## Summary

This version is the first release of `lucacodorean/ba-panel`.
It gives a minimal Laravel package skeleton. It has no panel, no route, and no configuration yet.

## Added

- Adds the Composer package `lucacodorean/ba-panel` with the `Lucacodorean\BaPanel\` namespace. (BAP-001)
- Adds the dependency `illuminate/support` `^13.5`. (BAP-001)
- Adds `Lucacodorean\BaPanel\BaPanelServiceProvider`. Laravel package discovery registers the service provider. The service provider does no work yet. (BAP-001)
- Adds the static method `BaPanelServiceProvider::routingTest()`. The method returns `true`. (BAP-001)
- Adds a test suite with Pest and Orchestra Testbench. One feature test checks that Laravel registers the service provider. (BAP-001)
- Adds the Composer script `composer test`. The script runs Pest. (BAP-001)

## Upgrade

1. Install the package with `composer require lucacodorean/ba-panel:0.1.0`.
