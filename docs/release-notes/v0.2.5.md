# v0.2.5

- **Date**: 2026-11-22
- **Previous version**: v0.2.0

## Summary

This version shows the documentation as an interactive graph on the panel page at `/ba-panel`.
You can open each document in a reader and filter the documents by name.
The feasibility agent panel is now hidden by default. A button on a menu bar at the right end of the page shows it.

## Breaking changes

- The panel view `ba-panel::panel` is replaced. The static file list, the static outline, and the static linked files are removed. The view now gets the graph data from the controller. **Action**: If you published the views, delete `resources/views/vendor/ba-panel`. Then publish the views again with `php artisan vendor:publish --tag=ba-panel-views --force`. Apply your custom changes again. An old published view shadows the package view and does not show the graph. (BAP-005, BAP-006)
- The markup of the panel page changes. The page has new elements, `data-*` attributes, and a menu bar. **Action**: Update all tests, styles, and scripts that use the old markup of the panel page. (BAP-005, BAP-006)
- The feasibility agent panel is hidden when the page opens. **Action**: Click the **Feasibility agent** button at the bottom of the menu bar to show the panel. (BAP-006)
- The route `ba-panel` now scans the paths in `BAP_DOCS_ARRAY` on each request. **Action**: Make sure that `BAP_DOCS_ARRAY` contains only the paths that you want to show. (BAP-005)

## Added

- Adds the documentation graph to the panel page. Each Markdown file in `BAP_DOCS_ARRAY` is one node. Each relation between two files is one edge. (BAP-005)
- Adds the scan of the configured paths. A configured `.md` file is used directly. A configured directory is scanned recursively for `.md` files. Hidden files and hidden directories are skipped. A path that does not exist is skipped. (BAP-005)
- Adds the YAML front matter keys `title` and `relations`. Both keys are optional. (BAP-005)
  - `title` is a string. Without it, the title is the first `# ` heading. Without a heading, the title is the file name.
  - `relations` is a list of paths. Write each path relative to the directory of the declaring file. An absolute path is also accepted.
  - Invalid YAML gives no metadata. The page does not show an error.
- Adds directed edges. When file A declares file B, the edge goes from A to B. When both files declare each other, the edge is bidirectional. Each pair of files gives one edge. (BAP-005)
- Adds the arrows to the graph. A one-way edge has an arrow at the target end. A bidirectional edge has an arrow at each end. The edges of the selected node use the accent color. (BAP-005)
- Adds a floating graph. You can drag a node. The section header shows the number of files and links. (BAP-005)
- Adds the document reader. The reader is hidden by default. Click a node to open the document. The reader shows the path, the rendered Markdown, and the linked files. The document scrolls inside the reader. (BAP-005, BAP-006)
- Adds the subgraph view. When you open a document, the graph shows only that document and its direct neighbours, in all directions. Click **Show all files** or close the reader to show the full graph again. (BAP-005)
- Adds safe Markdown rendering. The reader escapes raw HTML and removes unsafe links, for example `javascript:` links. The reader does not show the front matter. (BAP-005)
- Adds the name filter. The filter compares the query with the file names only. A name word that starts with a query word is a full match. Other words are compared with character trigrams, with a threshold of 0.8. The filter does not change the graph. (BAP-005)
- Adds the route `GET /ba-panel/documents/{node}` with the name `ba-panel.documents`. It returns JSON: `{id, name, title, path, html, relations: [{id, name, path}], subgraph: [id]}`. `{node}` is 12 lowercase hexadecimal characters. An unknown id gets a 404 response. (BAP-005)
- Adds the route `GET /ba-panel/search?q=` with the name `ba-panel.search`. It returns JSON: `{query, threshold, results: [{id, name, path, score}]}`. The query is trimmed and cut to 200 characters. A blank query returns no results. (BAP-005)
- Adds a menu bar at the right end of the page. The **Feasibility agent** button at the bottom of the menu bar is the only control that shows and hides the agent panel. When the panel is hidden, the documentation section uses the free width. (BAP-006)
- Adds the storage of the agent panel state. The browser stores the state in `localStorage`, with the key `ba-panel-agent` and the value `open` or `closed`. A missing or invalid value gives the closed state. (BAP-006)
- Adds the dependencies `league/commonmark` `^2.8` and `symfony/yaml` `^7.4|^8.0`. (BAP-005)
- Adds the documentation rules for the graph, the front matter, and the panel features to `README.md`. (BAP-005, BAP-006)

## Changed

- Changes the route `ba-panel`. A controller now serves the page and gives the graph data to the view. The URI, the route name, and the middleware do not change. (BAP-005)
- Changes the requests of the panel page to relative URLs. The panel now works behind an HTTPS reverse proxy, for example the ddev router. (BAP-005)

## Upgrade

1. Update the package with `composer require lucacodorean/ba-panel:^0.2.5`.
2. If you published the views, delete `resources/views/vendor/ba-panel`. Then run `php artisan vendor:publish --tag=ba-panel-views --force`. Apply your custom changes again.
3. Optional: add the `title` and `relations` front matter keys to your Markdown files. See the "Write documentation for the panel" section in `README.md`.
4. Update all tests, styles, and scripts that use the old markup of the panel page.
5. Open `/ba-panel` in the browser. To show the feasibility agent, click the button at the bottom of the menu bar.
