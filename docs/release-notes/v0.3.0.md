# v0.3.0

- **Date**: 2026-11-23
- **Previous version**: v0.2.5

## Summary

This version makes the feasibility agent work on the panel page at `/ba-panel`.
You send a change request or a feature request. The agent assesses it against the documents in the context.
The agent returns a structured feasibility report. You can read the report in the panel and download it as a `.md` file.
The package classes now get their services through dependency injection. Code that creates package classes with `new` must give all services.

## Breaking changes

- The package removes `Lucacodorean\BaPanel\Ai\BaPanelAgent`. The container now binds `Lucacodorean\BaPanel\Ai\FeasibilityAgent`. **Action**: Replace all uses of `BaPanelAgent` with `FeasibilityAgent`. (BAP-007)
- The panel view `ba-panel::panel` changes. It has a CSRF meta tag, a new context list, and new `data-*` attributes. **Action**: If you published the views, delete `resources/views/vendor/ba-panel`. Then publish the views again with `php artisan vendor:publish --tag=ba-panel-views --force`. Apply your custom changes again. An old published view shadows the package view and cannot send requests to the agent. (BAP-007)
- The `.pdf` export button is removed from the agent panel. **Action**: Use the `.md` export. (BAP-007)
- The constructors have no `= new X()` defaults. You must give each service. **Action**: Get the classes from the container, for example `app(DocumentRenderer::class)`. If you create a class with `new`, give all parameters. (BAP-007)
  - `DocumentRenderer(FrontMatterParser $frontMatter, SafeMarkdownConverter $converter)`. The constructor has a new second parameter.
  - `GraphBuilder(array $paths, string $basePath, FrontMatterParser $frontMatter)`.
  - `NameSearch(Tokenizer $tokenizer, Vectorizer $vectorizer, float $threshold = NameSearch::THRESHOLD)`.
- The order of the `NameSearch` constructor parameters changes. `$threshold` is now the last parameter. **Action**: Replace `new NameSearch(0.7)` with `new NameSearch(new Tokenizer(), new Vectorizer(), 0.7)`, or use named arguments. (BAP-007)

## Added

- Adds the feasibility agent `Lucacodorean\BaPanel\Ai\FeasibilityAgent`. It is a Neuron AI agent. It assesses one request against the documentation files in the context. Its context window is 150,000 tokens. The container builds its provider from `BAP_AI_PROVIDER`, `BAP_AI_MODEL`, and `BAP_AI_KEY`. (BAP-007)
- Adds `Lucacodorean\BaPanel\Ai\FeasibilityAssessor(DocumentRenderer $documents, ReportMetadataFactory $metadata)`. It builds one message with one block for each file. It removes the front matter of each file. Each request runs on a new thread. The agent keeps no chat history. (BAP-007)
- Adds the structured report `Lucacodorean\BaPanel\Reports\FeasibilityReport`. The report has nested classes in `src/Reports/` and 13 enums in `src/Reports/Enums/`. (BAP-007)
- Adds the report system fields in `ReportMetadata`. PHP fills these fields, not the model. The fields are the report id, the version, the status, the author, the dates, and the generator. The report id has the format `FR-YYYYMMDD-xxxxxx`. (BAP-007)
- Adds `Lucacodorean\BaPanel\Reports\ReportMetadataFactory(PackageVersion $version)`. Its `create(?DateTimeImmutable $now = null)` method creates the metadata of a new draft report. All dates of the report are `$now`. When you give no time, the method uses the current system time. Give a fixed time in a test. `ReportMetadata` has no `create()` method. (BAP-007)
- Adds `Lucacodorean\BaPanel\Reports\PackageVersion`. It reads the installed package version from Composer. It returns `dev` when Composer does not know the package. (BAP-007)
- Adds `Lucacodorean\BaPanel\Ai\FeasibilityAgentFactory(ProviderFactory $providers, Repository $config)`. Its `make()` method builds a new `FeasibilityAgent` from the `ba-panel.ai` config. The class is not final. A test or a host can extend it to give another AI provider. The class is `readonly`, so a subclass must be declared as a `readonly class`. The `FeasibilityAgent` container binding uses this factory. (BAP-007)
- `FeasibilityReport::metadata()` throws `LogicException` when no metadata is attached. `FeasibilityAssessor::assess()` attaches the metadata. If you build a report in another way, call `attachMetadata()` first. (BAP-007)
- Adds calculated values to the report. PHP calculates the risk severity and the total effort. The risk severity is the probability multiplied by the impact, from 1 to 25. (BAP-007)
- Adds the report view `ba-panel::reports.feasibility`. `FeasibilityReport::toMarkdown(Illuminate\Contracts\View\Factory $views)` renders the report as Markdown with this view. Give the view factory as the argument. Neuron AI creates the report, so the report cannot get the view factory in its constructor. The tag `ba-panel-views` publishes the view. (BAP-007)
- Adds the route `POST /ba-panel/feasibility` with the name `ba-panel.feasibility` and the `web` middleware. The route needs a CSRF token. (BAP-007)
  - The request is JSON: `{message, context}`. `message` has 5,000 characters or less. `context` is a list of 50 node ids or less.
  - Each node id is 12 lowercase hexadecimal characters. An id with a final line break is refused.
  - A valid request gets a 200 response: `{report, markdown, html}`.
  - An invalid request gets a 422 response.
  - When the AI provider is not configured, the response is 503.
  - When the agent or the provider fails, the response is 502. The package logs the error. The response does not show the error details.
- Adds `Lucacodorean\BaPanel\Markdown\SafeMarkdownConverter`. The document reader and the report HTML use it. It escapes raw HTML and removes unsafe links. (BAP-007)
- Adds `DocumentRenderer::body(Node): ?string`. It returns the Markdown body without the front matter. It returns `null` when the file cannot be read. (BAP-007)
- Adds the agent context to the panel. When you open a document, the context contains that document and all directly connected documents. (BAP-007)
  - Each file has one chip with a remove button. The context shows the number of files.
  - When you open another document, its files replace the context.
  - When you close the reader, the context is cleared.
- Adds the message composer. Press Enter to send. Press Shift+Enter for a new line. Click a suggestion to put its text in the input. (BAP-007)
- Adds the `.md` export. The button downloads the latest report as `feasibility-<report_id>.md`. (BAP-007)
- Adds the feasibility agent sections to `README.md`: the panel use, the PHP use, the endpoint, the report contents, and the report view override. (BAP-007)
- Adds tests for `FeasibilityAgent`, `FeasibilityAgentFactory`, `FeasibilityAssessor`, `FeasibilityReport`, `MarkdownText`, `ReportMetadataFactory`, `Risk`, `SafeMarkdownConverter`, the container bindings, and the feasibility endpoint. The agent, assessor, and endpoint tests use the Neuron `FakeAIProvider`. They do not call a real provider. (BAP-007)
  - The `ReportMetadataFactory` tests give fixed `DateTimeImmutable` values to `create()`.
  - `ReportDtoReadonlyTest` checks that a write to a property of each of the 10 nested report classes throws `Error`.
  - The test class `FakeFeasibilityAgentFactory` extends `FeasibilityAgentFactory`. It is `final readonly`. It gives the test provider to each agent.
- Adds the Pest architecture test `tests/Unit/ArchitectureTest.php`. It has 8 rules for the package classes in `src/`. (BAP-007)
  - All classes are `final`, except `FeasibilityAgentFactory`. `FeasibilityAgentFactory` is not `final`.
  - `FeasibilityAgentFactory` is `readonly`.
  - All classes are `readonly`, except 5 classes. The 5 classes are not `readonly`.
  - All classes in `Reports` are `readonly`, except `FeasibilityReport`.
  - The package does not use `Psr\Clock`.
  - The package does not call the global helpers `app`, `config`, `view`, `report`, `resolve`, `base_path`, and `logger`.

## Changed

- Changes `DocumentRenderer`. It uses `SafeMarkdownConverter` for the HTML. The rendered HTML does not change. (BAP-007)
- Changes the welcome text of the agent panel. It tells you that the open file and its linked files are added as context. (BAP-007)
- Changes all package classes to `final`, except `FeasibilityAgentFactory`. All classes that existed in v0.2.5 were already `final`. (BAP-007)
- Changes the package classes to `readonly` when their state never changes. PHP stops each write to their properties after the constructor. (BAP-007)
  - These classes are not `readonly`: `FeasibilityAgent`, `BaPanelServiceProvider`, `InvalidConfigurationException`, `InvalidFeasibilityRequestException`, and `FeasibilityReport`. Their parent classes or their behaviour do not permit it.
  - `FeasibilityAgentFactory` is `readonly`, but it is not `final`. If you extend it, declare your subclass as a `readonly class`. PHP refuses a subclass that is not `readonly`.
  - The nested report classes, for example `Risk` and `EffortTask`, use constructor properties. You can create them with `new` and named arguments. The JSON schema of the report does not change.
  - The classes from v0.2.5 that are now `readonly` had only private properties. Their public API does not change.
- Changes the service provider and the controllers. They get the config, the paths, the view factory, and the exception handler through injection. They do not call global helpers. The behavior does not change. (BAP-007)

## Removed

- Removes `BaPanelAgent` and its tests. (BAP-007)
- Removes the `.pdf` export button. (BAP-007)

## Known limitations

- The endpoint does not stream. The request waits for the full report.
- A slow or overloaded provider gives a 502 response with a general message. Examples: a Gemini 503 "high demand" error, or a provider HTTP timeout.
- The supported values of `BAP_AI_PROVIDER` are only `anthropic`, `openai`, `gemini`, `mistral`, `deepseek`, and `xai`. OpenAI-compatible endpoints, for example Groq or OpenRouter, are not supported yet.
- The generator version in the report shows a `dev` version when the package is not installed from a tag.

## Upgrade

1. Update the package with `composer require lucacodorean/ba-panel:^0.3.0`.
2. Replace all uses of `BaPanelAgent` with `FeasibilityAgent`.
3. If you create `DocumentRenderer`, `GraphBuilder`, or `NameSearch` with `new`, give all services. Put the `NameSearch` threshold last. Or get the classes from the container.
4. If you published the views, delete `resources/views/vendor/ba-panel`. Then run `php artisan vendor:publish --tag=ba-panel-views --force`. Apply your custom changes again.
5. Make sure that `BAP_AI_PROVIDER`, `BAP_AI_MODEL`, and `BAP_AI_KEY` are set in `.env`.
6. Open `/ba-panel` in the browser. Open a document, then open the feasibility agent and send a request.
