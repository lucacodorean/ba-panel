# v0.2.0

- **Date**: 2026-11-22
- **Previous version**: v0.1.0

## Summary

This version adds the environment contract, the configuration validation, and the first panel page at `/ba-panel`.
The panel page is a static stub. It shows the layout of the documentation reader and the feasibility agent.
The agent does not answer messages yet.

## Breaking changes

- The package needs PHP `^8.3`. **Action**: Run the application on PHP 8.3 or higher. (BAP-002)
- The package license changes from `MIT` to `proprietary`. **Action**: Make sure that your use of the package agrees with the new license. (BAP-002)
- The package removes `BaPanelServiceProvider::routingTest()`. **Action**: Remove all calls to this method. (BAP-002)
- When `BAP_ENABLED=true`, the application stops at boot if the configuration is not valid. **Action**: Set all required environment variables before you set `BAP_ENABLED=true`. (BAP-003)

## Added

- Adds the configuration file `config/ba-panel.php`. Publish it with the tag `ba-panel-config`. (BAP-003)
- Adds five environment variables: `BAP_ENABLED`, `BAP_AI_PROVIDER`, `BAP_AI_MODEL`, `BAP_AI_KEY`, and `BAP_DOCS_ARRAY`. (BAP-003)
- Adds the configuration validation at boot. The validation runs only when `BAP_ENABLED=true`. (BAP-003)
- Adds `Lucacodorean\BaPanel\Exceptions\InvalidConfigurationException`. The exception contains all validation errors. `errors()` returns them as a list. (BAP-003)
- Adds the route `GET /ba-panel` with the name `ba-panel` and the `web` middleware. The package registers the route only when `BAP_ENABLED=true`. (BAP-004)
- Adds the stub panel view `ba-panel::panel`. The view shows a documentation file list, a file reader, and a feasibility agent chat area. The send and export buttons are disabled. (BAP-004)
- Adds a light and a dark theme to the panel. The browser keeps the selected theme. (BAP-004)
- Adds the publish tag `ba-panel-views`. The tag copies the views to `resources/views/vendor/ba-panel`. (BAP-004)
- Adds the AI provider integration through `neuron-core/neuron-ai` `^4.1`. The supported values of `BAP_AI_PROVIDER` are `anthropic`, `openai`, `gemini`, `mistral`, `deepseek`, and `xai`. (BAP-004)
- Adds the feasibility agent `Lucacodorean\BaPanel\Ai\BaPanelAgent`. The container builds the agent from the `ba-panel.ai` configuration. The panel page does not use the agent yet. (BAP-004)
- Adds the dependencies `illuminate/routing` `^13.5` and `illuminate/view` `^13.5`. (BAP-004)
- Adds installation, configuration, route, and validation instructions to `README.md`. (BAP-003, BAP-004)
- Adds PHPStan `^2.3` as a development dependency, at level 6. (BAP-002, BAP-003)

## Changed

- Changes the package archive. Composer does not download `tests/`, `phpunit.xml`, `.ddev`, `.gitattributes`, and `.gitignore`. (BAP-002)
- Changes the test suite. It now has a `Unit` suite and a `Feature` suite. (BAP-003)

## Upgrade

1. Make sure that the application runs on PHP 8.3 or higher.
2. Update the package with `composer require lucacodorean/ba-panel:^0.2.0`.
3. Remove all calls to `BaPanelServiceProvider::routingTest()`.
4. Optional: publish the configuration with `php artisan vendor:publish --tag=ba-panel-config`.
5. To enable the panel, set `BAP_AI_PROVIDER`, `BAP_AI_MODEL`, `BAP_AI_KEY`, and `BAP_DOCS_ARRAY` in `.env`. Then set `BAP_ENABLED=true`.
6. Open `/ba-panel` in the browser.
